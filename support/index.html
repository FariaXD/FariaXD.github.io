Reporting a problem

These make a fix much faster:

  • Your Unity version, and which render pipeline the project uses
  • The steps that lead to the problem
  • Any errors or warnings from the Console, copied as text
  • A screenshot of the FrameForge window or Inspector, if the problem is visual

Before you write

Where is the documentation?

The full manual comes with the package, as a PDF in Assets/FrameForge/Documentation. The README.md in Assets/FrameForge has the same content.

My attack animates but never hits anything.

Check the Attack Player's Hit Mask includes the target's layer, and that Query Triggers is on if the target's collider is a trigger — a Hurtbox Driver's collider always is.

My boxes are on the wrong side when the character faces left.

Author every box facing right, and set the Attack Player's FacingSign to -1 when the character faces left. FrameForge mirrors the boxes for you.

Does it work with my Unity version?

FrameForge is developed and tested on Unity 6, and written to support Unity 2022.3 LTS and newer. If you hit a compile error on an older version, email me and it will be fixed.

Does it support 3D?

Not at the moment — FrameForge is built for 2D physics.
